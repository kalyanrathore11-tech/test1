# Hotspot Keeper v1.0

APK banane ke steps (Android Studio ki zarurat nahi):

1. github.com par free account banayein aur naya repository banayein (naam: HotspotKeeper).
2. "uploading an existing file" par click karke is ZIP ke andar ki saari files/folders upload karein
   (`.github` folder samet - ye zaruri hai) aur "Commit changes" dabayein.
3. Upar "Actions" tab kholein -> "Build APK" chalta dikhega (5-7 minute).
4. Green tick aane par us run par click karein -> neeche "Artifacts" me `HotspotKeeper-APK` download karein.
5. ZIP kholein, andar `app-debug.apk` milegi. Phone me install karein
   (Settings me "Install unknown apps" allow karna padega).

Build me error aaye to error ka screenshot/text mujhe bhej dein.
